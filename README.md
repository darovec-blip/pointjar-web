# pointjar.app

Verejné stránky mobilnej aplikácie **PointJar** — podpora, zásady ochrany
osobných údajov a podmienky používania (SK / CZ / EN / DE).

Stránky sa **negenerujú tu**. Vznikajú skriptom `scripts/generuj-web.mjs`
v súkromnom repozitári appky z tých istých textov, ktoré appka zobrazuje
vo vnútri, takže sa web a aplikácia nemôžu rozísť. Toto repo je len hosting
pre GitHub Pages.
